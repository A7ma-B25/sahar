## 1. Goal

He downloads one file in his browser. The next time Sahar's brain starts (or while it runs), she finds it, checks it,
switches to it by herself and tells him — no button. Her answers come from Qwen3.6-35B-A3B, on his laptop, offline.

## 3. Design

1. **Pin** the file in `ModelCatalog` as role `big` (not the default).
2. **Offload.Auto**: when the model file is bigger than the GPU's memory minus 1 GB, llama-server gets **no `-ngl`**
   and `--fit on --fit-target 1024` (llama.cpp places attention on the GPU and experts in RAM itself). CPU threads stay
   the computed count (experts compute on the CPU), still `--poll 0 --prio -1`.
3. **RAM guard**: a model bigger than RAM − 4 GB is not started (`too-big`); she says so in one line.
4. **Load deadline** scales with size: 120 s + 10 s per GB above 6 GB, at most 300 s (20.5 GB → 265 s).
5. **Chat budget** (model time per turn): 20 s, or 45 s when the active model is over 10 GB.
6. **Finder**: the Mind looks in his Downloads folder (Known Folder, fallback `%USERPROFILE%\Downloads`) and the models
   folder for a `.gguf` whose size equals a pin's and whose name starts with the pin's stem (browser copies like
   `…Q4_K_M (1).gguf` count; `.crdownload`/`.part` do not). At Mind start, and through a FileSystemWatcher while the
   Mind runs. Found → progress `found` («لقيت عقلي الكبير بالتنزيلات، عم اتأكّد منه…») → SHA-256 on a low-priority
   thread (`verifying`) → match: moved into the models folder when on the same drive (instant), otherwise used in place;
   marked installed; **made active once** (`bigAutoUsed` flag: never again if he switches back) → the existing `done`
   path (bench quick, «هلق صرت فكّر لحالي ✨»). Mismatch → `mismatch` line, the file is **not** deleted (it is his).
7. **Picked by hand** («زيدي نموذج» with a path): a file whose SHA-256 equals a pin marks that pin installed instead of
   adding an unknown "file:" model, so it gets the pin's name and role.
8. **Fallback**: if the big model fails to load (GPU then CPU), the previous installed model becomes active again and
   she says «عقلي الكبير ما اشتغل، رجعت للصغير».
9. **Page**: «النماذج» lists it with the role «العقل الكبير» and «بدّو ٣٢ غيغا رام، وبيكون أبطأ شوي بس أذكى بكتير».
