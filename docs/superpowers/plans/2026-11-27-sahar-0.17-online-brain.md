# Sahar 0.17 — the online brain (words only) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans (inline, TDD RED→GREEN, ledger in
> `.superpowers/sdd/0.17-ledger.md`). Steps use checkbox (`- [ ]`) syntax.

**Goal:** In the chat window she answers free words from an online model he chose (Groq → OpenRouter → custom → local),
streamed, long when needed, in the same persona; every action stays with the local decision-JSON brain.

**Architecture:** Core gets `Mind/Online/*` (profiles, the generalised `OpenAiClient`, router, policy, prompt, chain
turn, quota, sealed keys, persisted history) — pure and tested against recorded fixtures. Sahar.Mind routes each turn
before warming the local model and serves `online` messages (key, test, status, bench). The engine marks chat-window
turns, caches the Mind's online status, shows the toggle/badges and the thinking face; the settings app gets the
«العقل أونلاين» page through a new bridge file.

**Tech Stack:** C# .NET 10 (Core, Mind and engine Native AOT; JSON via Utf8JsonWriter/JsonDocument/source-gen),
xUnit v3, vanilla JS (node:test), PowerShell UI harness + a Python fake provider, GitHub Actions (no workflow edits).

**Spec:** `docs/superpowers/specs/2026-11-27-sahar-0.17-online-brain-design.md`

## Global Constraints

- Online for WORDS only: no tools, no decision JSON, no `response_format` online; the local TurnRunner loop is untouched.
- Background turns (initiative, routine, reflect) and drafts are never online; «محلي فقط» = zero online requests.
- Keys: typed by him, sealed by the Mind in her SecretBox (`online-keys`); never in settings.json, logs, repo, CI.
- Online HTTP uses the system proxy; local stays `UseProxy = false`; custom URLs https or loopback only.
- Logs: kinds, codes, HTTP status numbers, provider ids, ms and token counts only — never words, titles, file names,
  user name, keys, provider error bodies.
- Online `max_tokens` 1500; prompt capped at ~4000 estimated tokens (`PromptBuilder.Tokens`); local 256 / 220 chars stay.
- Retry once on 429/5xx (Retry-After ≤ 3 s, else 800 ms); every attempt counts in the local quota count.
- Default chain `groq, openrouter` (local always last); defaults `openai/gpt-oss-120b`, `google/gemma-4-31b-it:free`.
- UI words: Syrian, short, plain; emoji allowed in her speech; unworking buttons hidden; Porcelain style.
- Version 0.17.0; no push to main, no publish; no edits to `.github/workflows` or `tools/ci`.

## Review Focus

1. A provider that answers 200 with an empty or only-reasoning stream, or drops mid-stream after some words: the chain
   moves on and he never sees a half answer as final (test `OnlineTurn_MidStreamError_FallsThroughAndRestartsWords`).
2. The key typed with spaces/newlines, or an empty field saved: trimmed; empty = «امسحه» never a sealed empty key
   (`OnlineKeys_TrimsAndRefusesEmpty`).
3. His VPN off / DNS failure at the first byte: `offline` in < 13 s and local answers in the same turn
   (`OpenAiClient_ConnectFailure_IsOffline`, `OnlineTurn_AllOffline_FallsToLocal`).
4. Day change at midnight while she runs: the quota resets and the "told once" flag too (`OnlineState_NewDay_Resets`).
5. A line that is both an action and writing («اكتبلي ملاحظة…», «حطيلي مؤقت واشرحلي…»): stays local
   (`BrainRouter_ActionBeatsWriting`).
